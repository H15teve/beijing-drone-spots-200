# 首都禁飞区抢救航拍指南

用于筛选北京天安门周边 300 公里（不含北京市行政区）航拍目的地的单文件静态网页：收录 200 个 UOM 浅蓝色适飞空域候选点，附 2026-09-13 至 14 的 UOM 官方逐点核验结果。整页自包含，可离线打开。

- 在线使用：<https://h15teve.github.io/beijing-drone-spots-200/>
- 数据仓库：<https://github.com/H15teve/beijing-drone-spots-200>

## 功能

- **交互地图**：候选点按路线着色，支持按钮、滚轮、拖动和触控缩放（最大 32 倍）；红色虚线圆为天安门 300 km 半径圈；省级界为粗实线，地级市界为细虚线。
- **适飞区快照**：可开关的绿色面层，已按 2026-09-14 的 UOM 官方图层重新校正，重点反映北京以西相较 2026 年 5 月镜像缩减的区域；透明度可调。
- **点位详情**：点击地图圆点或表格行，查看坐标、距天安门距离、DJI 想飞/打卡/作品数、管控提示、边界分档、推荐时间与 UOM 核验日期。
- **建议评分**：100 分制，从景观构图、DJI 热度、边界稳定性、同线效率、光线时段、现场核验便利度六个维度逐项打分并说明理由。
- **筛选与排序**：按关键词、路线、景观、DJI 管控、边界分档筛选；按热度、建议评分、想飞数、作品数、距离排序；表格分页浏览。
- **CSV 导出**：一键导出当前筛选结果，便于离线分析。
- **清屏模式**：隐藏地图周边工具、图例与标尺，便于投屏或截图，再点“恢复”还原。
- **出行倒计时**：标题旁显示距 2026-09-20 08:00（北京时间，首都禁飞区正式启用）的实时倒计时。

## 如何使用

1. 打开网页，在左侧地图浏览、缩放，点击感兴趣的点位；右侧同步显示详情与评分明细。
2. 用筛选栏缩小范围（例如只看“相对稳定”边界或某条路线），地图与表格实时联动。
3. 需要离线研究时，点击“导出 CSV”保存当前筛选结果。
4. 确定目的地后，起飞当天务必回到 [UOM 官方平台](https://uom.caac.gov.cn/) 重新查询当日空域与临时管制。

## 重要声明

本项目仅用于行程研究，不构成飞行许可、审批意见、实时空域状态证明或安全保证。起飞前必须回到 UOM 官方平台查询当日空域、临时管制和适用的运行要求，并取得依法需要的批准与场地方同意；遇到任何冲突，以主管机关和现场管理要求为准。北京行政区域内点位未列入本榜。
