# 北京 300 km 航拍点公开研究版

这是一个可直接部署到 GitHub Pages 的静态单页网站。页面包含 200 个航拍候选点、DJI 平台统计与管控提示、2026-09-13 至 14 的 UOM 官方逐点核验结果，以及数据标注期为 2026 年 5 月的第三方适飞区镜像快照。

地图保持原有 100% 投影比例和左右范围，通过把 SVG 与左栏同步增高，只向北扩展至约北纬 43.36°；南界仍为约北纬 36.45°。济南及 300 km 圈外围城市仅作为地理参照，不改变“天安门 300 km 圆内、北京行政区外”的候选点筛选口径。外围地级市名称必须落在对应市域内部；仅有很小边角进入画面的远端城市不强制标名。地图快照已经裁切、以约 0.04 SVG 像素的容差简化并内嵌到 SVG，离线打开时不会再请求镜像站点。该显示容差在全图尺度约相当于 40 米，最大支持 32 倍缩放，可观察约 20 公里宽的局部视野；它只提升网页的几何显示保真度，不会提高镜像原始数据的法律效力或测绘精度。地图支持按钮、滚轮、拖动和触控缩放，可点击航拍点切换右侧详情，可开关绿色适飞区面层并调节透明度。省级边界使用较粗连续线，地级市边界使用较细虚线。“清屏”可隐藏地图四周的工具、图例和标尺，再次点击“恢复”即可还原。地图与右侧详情栏采用等高布局，并移除了详情顶部的装饰空白。“一周建议”采用 100 分制，详情中逐项解释景观、热度、边界稳定性、同线效率、光线时段和现场核验便利度。

## 重要声明

本项目仅用于行程研究，不构成飞行许可、审批意见、实时空域状态证明或安全保证。起飞前必须回到 UOM 官方平台查询当日空域、临时管制和适用的运行要求，并取得依法需要的批准与场地方同意。

页面保留周边地级市边界和城市名称，用于路线识别；这些边界不表示 UOM 法定空域或飞行许可。计划部署于 GitHub Pages 并不自动解决第三方数据许可或所有可能适用的法律义务，发布者仍需自行核查。
